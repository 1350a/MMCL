# MMCL UI 设计文档

- 阶段：见 [STATUS.md](./STATUS.md)；落地顺序见 §8
- 关联：[DESIGN.md](DESIGN.md) §4 架构不变；本文档只约束 UI/交互层，与 DESIGN.md 冲突时 UI 范畴内以本文档为准
- 来源：2026-11-22/23 与产品决策人的十七轮收敛讨论，全部条目已无异议
- 约定：UI 展示层术语只用「版本」「.minecraft 文件夹」，不出现「实例」；代码内部 instances 命名暂不动

## 1. 总览与视觉

- 目标平台：Windows x64 优先；分发为安装包（非便携版）
- 色调：**浅色主题**（2026-11-23 实施验收定版）——默认背景图偏暗，上面叠**白化图层**（`--mcl-bg-wash` 白幕，变淡变白）再配深色文字与白色半透明玻璃表面；多色系：靛蓝主色（**非纯蓝**）+ 琥珀强调（火把）+ AI 紫 + 草绿成功，渐变语言 indigo→cyan（主操作）、violet→indigo（AI）、amber→orange（启动按钮）；具体色值进 tokens.css（见 §8）
- 动画：**活泼弹性档**——快 180ms / 标准 320ms / 强调 450ms；入场/展开用过冲弹性曲线 `cubic-bezier(0.34, 1.56, 0.64, 1)`，**退场一律配对实现**（弹窗/通知滑出淡出）；`prefers-reduced-motion` 全降级
- 主页 = 顶栏 + 左侧栏 + 底栏三大件 + 中心区；侧栏玻璃背景（浅色 `rgba(255,255,255,0.66)` + blur，**非纯透明**）；任务与最近对话面板紧随导航不沉底（2026-11-23 验收修正）
- 背景：整个窗口一张图 + 白化图层（替代原「80% 不透明度」单层方案，2026-11-23 定版）；默认背景已内置（夜景 MC 截图 1920×1200，`renderer/src/assets/background.png`），自定义背景入口在设置页
- Mods 管理归属**下载页**（本地安装/列表删除；Modrinth 搜索 UI 后置，AI 对话可装；操作对象跟随底栏当前选中版本；2026-11-23 拍板，C6 已实装）
- 弹窗原则：应用内弹窗只装确认/通知等轻事务（不用 Windows 原生对话框做**业务弹窗**）；过程性反馈走右下角 IDE 式通知（§6）

## 2. 信息架构

### 2.1 中心区（主页）

- 默认 = AI 对话面板：一句标题 + 输入框；输入框右下角从右到左为圆形发送按钮、选择模型下拉（展开含「配置模型」→ 跳设置页）
- 未配置 API key：显示引导面板（配置 key 或禁用 AI），仅首次引导
- AI 被禁用：中心为留白艺术（仅背景透出）
- 后期可选：RAG（若不追求极致轻量）

### 2.2 侧栏

- 上半部分 = 功能入口：主页 / 插件 / 下载
- 下半部分 = 任务列表 + 最近对话
- 收起：仅首页可收起，通过快捷键（Ctrl+B 类）；其他页面恒展开
- 隐藏：设置页里选择隐藏（最初设想保留）
- 挂件按钮：仅收起/隐藏态出现，位置左上方、顶栏下方，点击唤回；切换支持按钮 + 快捷键
- 折叠态样式（图标列/窄标签）实施期定

### 2.3 底栏

- 左：账号头像 + 铅笔下拉按钮
  - 未配置账户：下拉显示「选择登录方式」→ 应用内中心弹窗三选：正版（暂不可实装，禁用态）/ 离线 / 外置登录（Authlib-Injector）
  - 已配置：账号列表（点击切换）+ 添加账号（复用三选弹窗）+ 管理/删除
- 右：版本选择器 + 启动游戏按钮（矩形）
  - 无可启动版本：按钮变「下载游戏」，副标题「没有可用的游戏版本」
  - 游戏运行中：按钮原位变「停止游戏」——点击直接停止，**无确认弹窗**；关闭逻辑必须扎实（进程树完整终止、等待退出、按钮状态复位），丢档风险由用户自担

### 2.4 设置

- 形态：**页面**（非小窗口）；底栏设置按钮一键直达，无下拉菜单
- 布局：左侧分组导航（外观 / 版本与隔离 / Java / 网络 / 通用）+ 右侧内容面板
- 收纳项：隐藏侧栏、自定义背景、AI key 与模型、版本隔离策略（§3）、更新检查（§5）、Java 获取方式（未实装项显示但禁用，带「未实装」提示）
- C7 实装定稿（2026-11-23）：
  - 外观：自定义背景（系统文件对话框 → 复制入 `.mmcl\background\custom.*`，主进程读 data URL ≤8MB 即时生效，可恢复默认）/ 隐藏侧栏（持久开关，挂件按钮唤回，≠ Ctrl+B 收起）/ 启用 AI（关闭 = 主页留白，§2.1）
  - 版本与隔离：全局策略五选（变更前 `isolation:preview` 列出有效隔离翻转的「跟随全局」版本，确认弹窗后才落盘——§3 时机①）/ 版本本体自动清理开关
  - Java：javaPath 保存并探测 / 内置运行时列表 + 一键下载（与下载页共用同一组件）/「自动获取运行时（按版本引导）」禁用项带「未实装」
  - 网络：下载源偏好单选（官方 / BMCLAPI 镜像）+ 官方失败引导切换说明
  - 通用：AI 配置（baseURL / apiKey / model）/ 扩展「AI 生成的扩展自动加载」开关（默认关，关闭时生成后只保存）/ 更新检查四选（选「不检查更新」弹确认框）/ 关于（版本号、非官方产品声明、ISC 许可、素材权利声明占位）

### 2.5 下载页

- 结构自上而下：**版本安装**（远端清单选择/安装/取消 + 进度条；已安装列表，非 Fabric 版本带「装 Fabric」）→ **Mods 管理**（操作对象跟随底栏当前选中版本，本地 jar 安装 + 列表删除；Modrinth 搜索属增强后置）→ **Java 运行时**（内置列表 + 常用 LTS 一键下载，进度走任务列表/通知；javaPath 手动配置归设置页）→ **游戏根目录**（当前根展示 + 系统原生目录选择，切换重启生效）
- 官方下载源失败 → 通知带动作「转用 BMCLAPI 镜像」，点击才写偏好（下次安装优先镜像清单，库下载本就有镜像回退，不静默切换）

### 2.6 插件页

- 结构自上而下：**扩展管理**（已安装扩展列表：id/name/version、能力 chips、fs/net 作用域、状态「运行中 / 待激活 / 未加载」、启用/停用、移除；空态引导「对 AI 说『帮我写一个扩展』」）→ **扩展面板**（扩展声明的 `text`/`kv`/`button` 声明式 UI，按钮回流 `ext:panel-action`）
- 生成语义（C8）：AI `generate_extension` 生成即保存到 `extensions/<id>/`，默认写 `.disabled` 标记不装载；用户可在本页手动启用/停用（重启保持），或到设置页开启「AI 生成的扩展自动加载」
- 不再提供「待审提案」卡；旧的审核/批准/拒绝链路已删除

## 3. 版本模型与隔离

- 版本 = 文件夹（如 `1.8/`，可启动档案，名字默认取游戏版本号如 `1.20.1-Fabric`，可改名）；根 .minecraft 唯一
- 版本隔离本质 = 启动时给游戏传的 gameDir 指向：关 → 根目录；开 → 版本文件夹。saves/screenshots/options/logs/mods/config 跟 gameDir 走；assets/libraries/版本本体由启动器从根传参注入、永远共享（MC 原生机制，无需回退逻辑）
- **隔离策略（单选下拉，五项，默认「全部开启」）**：

| 策略              | 原版正式版 | 原版快照 | mod版（正式本体） | mod版（快照本体） |
| ----------------- | ---------- | -------- | ----------------- | ----------------- |
| 全部开启（默认）  | ✓          | ✓        | ✓                 | ✓                 |
| 全部关闭          |            |          |                   |                   |
| 仅隔离快照版      |            | ✓        |                   | ✓                 |
| 仅隔离mod版       |            |          | ✓                 | ✓                 |
| 隔离快照版和mod版 |            | ✓        | ✓                 | ✓                 |

- 判定材料：版本类型（snapshot/release）+ 是否装加载器（versionId 元数据已有）
- **双层实时层叠**：全局策略在设置页；每版本策略在版本设置（右下角版本选择器展开进入）。每版本默认「跟随全局」，选具体策略即覆盖；全局改动影响所有「跟随全局」的版本
- 中心弹窗确认的两个时机：① 隔离从开启变关闭时（含全局变更波及的跟随版本）② 隔离开启状态下删版本文件夹
- 删除语义：隔离关闭时只删版本条目与启动文件，根目录 saves/mods 不动，弹窗告知；本体（versions/<id>/ 的 jar+清单）无任何版本引用时**自动清理**，设置可调
- 配置存放：全局配置 = `.mmcl\mmcl.json`（JSON 格式）；版本级配置（隔离开关、JVM 参数）= 版本文件夹内

## 4. 目录与数据

```
%USERPROFILE%\.mmcl\           ← 启动器自身数据
├─ mmcl.json                   ← 全局配置（含 lastGameRoot、lastVersionId、更新设置、AI key 明文、UI 偏好）
├─ workspace\                  ← AI 写脚本的文件夹（工作区），恒定此路径，永不指向 .minecraft（防污染）
└─ .minecraft\                 ← 兜底游戏根（无官启目录时新建，或用户主动选择新建）
```

- 游戏根选择：启动读取记忆的上次路径（存在 → 直接用；消失 → 日志报错 + 备用模式新建 `.mmcl\.minecraft`）；**首次**（无记忆）才探测官启 `%APPDATA%\.minecraft`，有 → 用它（存在即可用，缺什么文件夹补建什么），无 → 新建
- 「新建 .minecraft 到 .mmcl」入口放在下载页，实装为**游戏根选择**（系统原生目录对话框；选目录即写 lastGameRoot + 补建标准目录 + 遗留迁移幂等重跑，**重启启动器后生效**——gameRoot 在启动装配期解析，不做热切换）
- 首版单工作区，架构预留多工作区扩展

## 5. 加载管线（Splash 六步）

Splash = Electron 无边框小窗（否决原生 stub exe——守住全栈 TypeScript 约定）；完成后淡入主页。动画 = logo + 当前步骤文字 + 细进度条；单步超时（约 15s）按失败处理。

| #   | 步骤                                                            | 阻塞       | 失败处理                                   |
| --- | --------------------------------------------------------------- | ---------- | ------------------------------------------ |
| 1   | 配置读取（mmcl.json，损坏→重置默认）                            | 阻塞       | 自动重置默认，继续                         |
| 2   | 工作区检查（记忆上次根 / 首次探测官启）                         | 阻塞       | 日志报错 + 备用模式新建 `.mmcl\.minecraft` |
| 3   | 版本初始化（ensureDefaultInstance、扫描已装版本、恢复上次选择） | 阻塞       | 错误面板：重试 / 仍进主页（无版本空态）    |
| 4   | 扩展注册（M5 组件加载；**可能最耗时**）                         | 非阻塞后台 | 进主页后右下角通知，进度进任务列表         |
| 5   | 更新检查                                                        | 非阻塞后台 | 见下；检查逻辑待有更新服务器后实装，先留位 |
| 6   | UI 预热（主窗口创建、主页资源预载）                             | 阻塞       | ——                                         |

更新检查为用户四选配置：检查并自动更新 / 检查并提醒更新 / 检查并仅提醒重要更新 / 不检查更新（选择「不检查」时弹简单确认框）。当前无更新服务器，仅落地设置项与管线留位。

## 6. 通知与任务

- 右下角 IDE 式通知：瞬时提醒，堆叠，可带动作按钮（取消 / 查看详情 / 停止 / 打开日志）；点击跳任务列表
- 侧栏任务列表：进行中 + 近期任务的持久面板（下载、启动、扩展注册等）
- 下载/启动全过程反馈走通知；错误详情点「查看详情」开应用内弹窗

## 7. 窗口与安装

- 窗口：`titleBarStyle: 'hidden'` + `titleBarOverlay`（自绘顶栏内容，系统渲染 ─ □ ✕；symbolColor 可随主题）——**不用 frame:false**，因此无需窗口控制 IPC，保留 Aero Snap / DPI / Win11 圆角
- 顶栏其余区域 `-webkit-app-region: drag`，交互子元素 `no-drag`
- 安装器（归属 M7+，不阻塞 UI 重构）：electron-builder NSIS；per-user 先做（%LOCALAPPDATA%\Programs，免管理员；「安装时选范围」后期考虑）；流程 = 协议页（**先用预设文本占位**，条款后议）→ 安装目录选择在主流程直接给 → 快速安装；自定义安装选项 = 任务栏固定 / 桌面快捷方式 / 开始菜单（注册表、环境变量不做；任务栏 pin 非 NSIS 标准能力，实施期验证）；卸载器 NSIS 自带
- 文件选择（自定义背景图、Java 路径等）= 系统原生对话框
- 下载源：官方源优先，超时/特慢 → 引导用户选择是否转 BMCLAPI（不静默切换）；属通用设置

## 8. 渲染层结构与落地顺序

```
renderer/src/
  App.tsx              # 导航状态 + 全局 Provider + Splash→主页装配
  styles/
    tokens.css         # 蓝色基调、背景 opacity、间距/圆角/字号（CSS 变量）
    global.css         # reset + @layer(ui,layout,pages,dialogs) 声明
  components/
    ui/                # Button / Modal / Select / Field / Notification
    layout/            # TitleBar / SideBar / BottomBar / HomeCanvas / Splash
    pages/             # DownloadPage / SettingsPage / ExtensionsPage / LogPage
    dialogs/           # LoginMethodDialog / ConfirmDialog / ErrorDialog / PermissionDialog
  hooks/               # useIpc / useSettings / useTasks
  state/               # context + useReducer（不引状态库）
```

纯原生 CSS 实现（Electron 33 = Chromium 130，`@layer`/`@scope`/CSS 变量足够），不引 CSS Modules、不引 Tailwind。

落地顺序（每步一笔 commit，typecheck + 测试通过才进下一笔；完成状态见 [STATUS.md](./STATUS.md)）：

1. M6 验收（前置，与 UI 重构无关）
2. 纯搬运拆分（行为零变化）
3. tokens + `@layer` 样式组织
4. TitleBar(overlay) + Splash + 三大件骨架
5. 下载页 → 设置页 → 插件页逐个接入
6. 安装器 = M7+ 另立里程碑

不变式：IPC 三处同步（main handler → preload 暴露 → env.d.ts 类型）· core 禁 import electron/react · 渲染层无 Node · 安全基线（contextIsolation/sandbox/nodeIntegration=false/window.open 拦截）一字不动。
